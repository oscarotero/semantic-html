# Toast snackbar

Component used to *reinforce* updates in the UI (like success or error messages).

## Success message

```html
<div role="status">
<!-- Inject success message here -->
</div>
```

## Error message

```html
<div role="alert">
<!-- Inject error message here -->
</div>
```
